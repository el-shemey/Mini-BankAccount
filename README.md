# 🏦 Mini Bank Account

A simple wallet management system developed using Python and Object-Oriented Programming (OOP).

## Features

* Create a wallet with a name, balance, and PIN.
* Check account balance.
* Verify PIN.
* Change PIN.
* Deposit money.
* Withdraw money.
* Prevent withdrawals exceeding the available balance.
* Validate deposit and withdrawal amounts.

## Technologies Used

* Python
* Object-Oriented Programming (OOP)

## OOP Concepts

* Classes and Objects
* Constructors
* Encapsulation
* Methods
* Private Attributes

## How to Run

1. Clone or download the repository.
2. Open the project in your Python environment.
3. Run `WalletV1.py`.
4. Use the `Wallet` class methods to perform banking operations.
